2. Google Sheet · a teammate can do this

  1. How

    New Google Sheet → Extensions → Apps Script → delete what’s there → paste everything from backend/sheet/Code.gs → Save.

  2. How

    Pick setup in the function menu at the top → Run → allow access. If Google says it hasn’t verified the app, click Advanced → Go to avail. It’s your own script. A box then shows the key.

    Copy: Sheet key
  3. How

    Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone → Deploy.

    Copy: Sheet URL (ends in /exec)

3. Groq · a teammate can do this

  1. How

    Sign up at console.groq.com (free plan) → API Keys → Create API Key.

    Copy: Groq key (starts with gsk_)

4. Facebook · whoever will own the Meta app

  1. How

    Any name, like “avail demo resort”. Don’t use the resort’s real page. Use an established Facebook account: brand-new ones sometimes get blocked from Meta’s developer tools.

  2. How

    developers.facebook.com → register as a developer if asked → My Apps → Create App → pick the Messenger option (Business type if it asks).

  3. How

    In the app’s Messenger settings, connect your test page, then click Generate token. If replies stop working later, generate a new one.

    Copy: Page token
  4. How

    App roles → Add Testers. Each teammate has to accept the invite. Until Meta reviews the app, only people with a role on it get replies.

5. n8n

  1. How

    Free trial at n8n.io. Note when the trial ends.

  2. How

    Credentials → Create. The names must match exactly, because the workflows find them by name:

    • avail Sheet key: Query Auth. Name key, value = your Sheet key.
    • avail Groq: Header Auth. Name Authorization, value = Bearer + your Groq key (with the space).
    • avail Facebook page: Query Auth. Name access_token, value = your Page token.
  3. How
    • Workflows → Create → ⋯ → Import from File, once for each file in backend/n8n/my-workflows/ on this computer. Your Sheet URL is already filled in there. (Using the blank copies in backend/n8n/workflows/ instead? Then paste the Sheet URL into the Config node of all three.)
    • In “avail · Owner app” Config, set ownerKey to a long word you make up.
    • In “avail · Messenger”, open “Check the verify token” and replace CHANGE-ME-TOO with another word you make up.
    Keep: Owner key Verify token
  4. How

    Click Publish on each workflow. Then open the nodes “Guest message comes in” and “Owner app request”, switch to Production URL, and copy both.

    Copy: Messenger URL Owner app URL

6. Connect Messenger to n8n

  1. How

    Meta app → Messenger settings → Configure webhooks. Callback URL = your Messenger URL. Verify token = your verify token → Verify and save. Then subscribe your page to messages.

7. The owner app on a phone

  1. How

    Repo Settings → Pages → Deploy from a branch → main, / (root). The repo has to be public on a free GitHub plan. The app will be at https://<your-github-name>.github.io/avail/app/.

  2. How

    Open that address on the phone → Settings → turn off sample data → paste the Owner app URL and your owner key → Save and connect. Then add it to the home screen.

8. Try it

  1. How

    From a tester’s Facebook account, message the page: “avail pa po Nov 20? 15 kami overnight”. The price should come back within a few seconds, and Nov 20 should show as Saved in the app. If not, open Executions in n8n and look for a red node.
