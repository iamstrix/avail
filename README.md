# avail

**Fill your empty days.**

avail helps small private pool resorts in the Philippines get bookings on empty days and reply to every guest right away. It works inside the resort's existing Facebook page and Messenger.

- **Empty days:** the owner taps the empty days on a calendar, and avail writes a Facebook post for them, with a perk (free breakfast, or late checkout when the next day is free) instead of a discount.
- **Fast replies:** when a guest messages, avail reads the message, works out the exact price, and saves the day for that guest until the GCash downpayment comes in. The owner checks GCash and confirms with one tap.

AI reads the messages and writes the posts. Prices are always worked out by code from the owner's own price list. The owner makes the final call.

Built for Build-Off: Business Edition 2026 (Sales and Marketing Solutions).

## The real build

| Folder | What it is |
|---|---|
| [`app/`](app/) | The owner's phone app: calendar, promo posts, saved days, confirmations, prices. Works with n8n, or in demo mode with sample bookings. |
| [`backend/engine/engine.js`](backend/engine/engine.js) | All the plain-code rules: prices, perks, replies, owner actions. The same file runs in n8n, in the app's demo mode and in the tests. |
| [`backend/sheet/Code.gs`](backend/sheet/Code.gs) | The Google Sheet's data script. n8n reads and writes the Sheet through it, one change at a time, so two guests can't save the same day. |
| [`backend/n8n/workflows/`](backend/n8n/workflows/) | The three n8n workflows to import: Messenger, Owner app and Timer. Generated by `backend/n8n/build.mjs`. |
| [`backend/test/`](backend/test/) | Tests, plus fake Facebook, Groq and Sheet services for testing the workflows on one computer. |
| [`SETUP.md`](SETUP.md) | Step by step: Google Sheet, Groq, Facebook, n8n, the owner app and phone alerts. |
| [`TECH-STACK.md`](TECH-STACK.md) | How the pieces fit together, in plain words. |

Try the owner app without setting anything up:

```bash
python -m http.server 8765
```

Then open `http://localhost:8765/app/`. It starts in demo mode.

Run the tests:

```bash
node --test backend/test/engine.test.js backend/test/sheet.test.js
```
